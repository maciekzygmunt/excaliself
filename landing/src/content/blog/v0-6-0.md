Excaliself v0.6.0 adds single sign-on. Members can now sign in with Google Workspace, Microsoft Entra ID, or one OIDC provider such as Okta, Authentik, or Keycloak. This release also moves the setup and usage docs onto this website.

Excaliself is a self-hosted [Excalidraw](https://excalidraw.com) with accounts, folders, search, live collaboration, and an MCP server. If you have not seen it, start with the [home page](/).

## What's new

### Single sign-on

Each provider turns on when you set its environment variables, and adds a **Continue with …** button to the sign-in page. Email and password sign-in and invites keep working.

How people get in:

- **Existing members** sign in with any provider whose email matches their account.
- **New people** get an account on their first SSO sign-in only if their email domain is in `SSO_ALLOWED_DOMAINS`. Everyone else still needs an invite link.

For example, to let Google Workspace users from `acme.com` join without an invite:

```bash
# in your .env
BASE_URL=https://draw.acme.com
SSO_ALLOWED_DOMAINS=acme.com
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
```

Register `<BASE_URL>/api/auth/callback/google` as the redirect URI with Google, then restart the app. The [Single sign-on guide](/docs/single-sign-on/) covers Microsoft and OIDC too, including what each provider lets an allowed domain claim.

### Docs on the website

Setup and usage docs are now at [excaliself.com/docs](/docs/). The deployment guide moved there from `docs/deployment.md` in the repo. There are pages for [Docker Compose](/docs/docker-compose/), [Coolify](/docs/coolify/), [environment variables](/docs/environment/), [backup and restore](/docs/backup-restore/), and [connecting an AI client](/docs/mcp/).

### A star prompt for admins

Admins see a small prompt in the sidebar one time, and a permanent link in **Settings → Instance**. Members who are not admins see nothing.

### Fix

**Settings → Instance** now shows the real version. It always showed `v0.1.0` before.

## Before you upgrade

- There are **no database migrations**. You can go back to v0.5.0 without a restore.
- SSO is optional. If you set no SSO variables, nothing changes.
- When an existing member signs in with SSO for the first time, their account links by email. This **removes their password, signs out their other sessions, and revokes their MCP access tokens**. An admin reset link gives the password back.
- The app does not start if a provider has only some of its variables set, or if `MICROSOFT_TENANT_ID` is `common`, `organizations`, or `consumers`.
- For OIDC, existing members can link only if your provider sends `email_verified: true`.
- Run one replica only, as before.

## Upgrade

The image is `ghcr.io/maciekzygmunt/excaliself:0.6.0` (also `:0.6` and `:latest`), for amd64 and arm64.

With Docker Compose:

```bash
docker compose pull && docker compose up -d
```

On Coolify, redeploy. See [Docker Compose](/docs/docker-compose/) or [Coolify](/docs/coolify/) for details.

The full list of changes is in the [v0.6.0 release notes](https://github.com/maciekzygmunt/excaliself/releases/tag/v0.6.0).
